# DebtBook

**DebtBook** — Android-приложение для небольших магазинов и малого бизнеса, предназначенное для удобного учёта долгов клиентов, платежей и истории операций.

## Основные возможности

### 👥 Клиенты и долги
- Добавление и управление клиентами.
- Учёт задолженности и платежей.
- История финансовых операций.
- Расчёт текущего баланса.
- Offline-first работа с локальными данными.

### 🏪 Магазины и сотрудники
- Создание магазина.
- Поддержка ролей **OWNER** и **EMPLOYEE**.
- Изоляция данных между магазинами.
- Управление составом сотрудников.
- Серверная проверка прав доступа через Supabase RLS.

### 🔐 Аутентификация и безопасность
- Вход через Google.
- Регистрация и вход через Email.
- Подтверждение Email.
- Android Deep Link для подтверждения аккаунта.
- Supabase Auth + PostgreSQL.
- Row Level Security (RLS).
- Защита от доступа к данным других магазинов.
- Чувствительные данные не выводятся в логи.

### 💬 Обратная связь
- Сообщения об ошибках.
- Предложения идей.
- Вопросы и другие обращения.
- Техническая информация об устройстве и версии приложения.
- Опциональные скриншоты.
- Сохранение отзывов в Supabase.

## Технологии

- **Kotlin**
- **Jetpack Compose**
- **Android**
- **Room**
- **Supabase**
- **PostgreSQL**
- **Row Level Security**
- **Kotlin Coroutines / Flow**

Архитектура построена с разделением UI, Domain и Data слоёв и с учётом offline-first подхода.

## Текущий статус

**Beta / Pre-1.0**

Основное MVP-ядро приложения реализовано. Готовы аутентификация, локальный учёт долгов, магазины, роли владельца и сотрудника, базовая серверная инфраструктура и система обратной связи.

Проект находится на этапе дальнейшего тестирования, усиления безопасности и подготовки коммерческой модели.

## Ближайшие и планируемые функции

### 🤖 Telegram Admin Bot
Административная система для управления пользователями и доступом:
- просмотр пользователей;
- выдача **FREE / PRO / BETA**;
- глобальное управление Beta;
- бан и разбан пользователей;
- удаление пользователей с учётом связанных магазинов;
- отображение статуса заблокированных аккаунтов.

### ⭐ PRO и Beta
- Бесплатный **FREE**-план с ограничениями.
- **PRO** с расширенными возможностями.
- Закрытый **BETA**-доступ с возможностями PRO.
- Централизованное серверное управление доступом.
- Интеграция с **Google Play Billing**.
- Серверная проверка покупок и подписок.
- Наследование доступа сотрудниками от владельца магазина.

### 🎖️ Система рангов должников
Игровая визуализация размера задолженности:
- динамический расчёт ранга по текущему долгу;
- звания и значки;
- отдельный экран с системой рангов;
- функция будет доступна в PRO.

Ранг является только визуальным элементом и не влияет на права доступа или безопасность.

### 📊 Дополнительные возможности
- Экспорт списка должников в **Excel / PDF**.
- Встроенный блокнот магазина.
- Аналитика.
- Улучшенная работа нескольких устройств.
- Полноценная синхронизация данных.
- Audit Log критических действий.

### 🛡️ Безопасность и инфраструктура
- Серверная валидация финансовых операций.
- Защита от подмены клиента и модифицированных APK.
- Rate limiting и защита API.
- Безопасное разделение Development / Staging / Production.
- Масштабирование Supabase и фоновых процессов.
- Резервное копирование и контроль миграций.

## Цель проекта

DebtBook создаётся как простой и надёжный инструмент для малого бизнеса, способный заменить бумажный учёт долгов централизованной системой.

В дальнейшем проект будет развиваться в полноценную систему управления магазином с несколькими сотрудниками, синхронизацией, аналитикой и коммерческими функциями.
