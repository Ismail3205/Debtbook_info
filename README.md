# DebtBook

**DebtBook** — Android-приложение для небольших магазинов и малого бизнеса, которое помогает вести учёт долгов клиентов в одном месте.

## Зачем нужен DebtBook

Во многих небольших магазинах долги постоянных клиентов всё ещё записываются в тетрадь, заметки телефона или таблицы. Это неудобно, повышает риск ошибок и затрудняет совместную работу нескольких продавцов.

DebtBook объединяет учёт клиентов, долгов и платежей в одном приложении.

## Основные возможности

### 👥 Клиенты и долги
- Добавление и управление клиентами.
- Отображение текущей задолженности.
- Регистрация платежей.
- История операций.
- Расчёт баланса на основе операций.

### 🏪 Магазин и сотрудники
- Создание магазина.
- Роли **OWNER** и **EMPLOYEE**.
- Приглашение сотрудников по PIN-коду и QR-коду.
- Просмотр состава команды.
- Удаление сотрудников владельцем.
- Серверная проверка прав доступа.

### 🔄 Offline-first и синхронизация
- Работа с локальными данными без постоянного подключения к интернету.
- Сохранение изменений локально.
- Синхронизация с Supabase.
- Outbox для надёжной отправки изменений.
- Защита от повторной загрузки одних и тех же операций.
- Изоляция данных разных магазинов.

### 🔐 Безопасность
- Google и Email-аутентификация.
- Supabase + PostgreSQL.
- Row Level Security (RLS).
- Серверная проверка ролей и членства в магазине.
- Append-only подход для финансовых операций.
- Защита от доступа к данным другого магазина.
- Редактирование и критические действия авторизуются на сервере.
- Чувствительные данные не должны попадать в логи.

### 💬 Обратная связь
Для Beta-тестирования предусмотрена MVP-система обратной связи:
- сообщение об ошибке;
- предложение идеи;
- вопрос;
- другой тип обращения;
- техническая информация о версии приложения и устройстве;
- опциональный скриншот.

Отзывы сохраняются в Supabase и используются для дальнейшего улучшения приложения.

## Технологии

- **Kotlin**
- **Jetpack Compose**
- **Android**
- **Room**
- **Supabase**
- **PostgreSQL**
- **Row Level Security (RLS)**
- **Kotlin Coroutines / Flow**

Проект использует разделение на UI, Domain и Data слои и построен с учётом offline-first подхода.

## Текущий статус

**Beta → Pre-1.0**

Основной функционал реализован, включая offline-first синхронизацию (outbox, инкрементальный pull, разрешение конфликтов по времени изменения). Security-аудит проведён, часть найденных замечаний ещё устраняется. Перед стабильным релизом остаётся:

- полевое тестирование и синхронизация между устройствами;
- закрытие оставшихся замечаний аудита;
- регрессионное и UX/UI-тестирование.

## Ближайшие планы

- **Подписка PRO/Beta** — серверная проверка доступа, Google Play Billing, лимиты для FREE-плана.
- **Система рангов должников** — игровая визуализация задолженности (PRO-фича, не влияет на доступ и безопасность).

## Цель проекта

DebtBook создаётся как простой и надёжный инструмент для малого бизнеса, позволяющий заменить бумажный учёт долгов централизованной системой.

В дальнейшем проект может расширяться аналитикой, уведомлениями, экспортом данных и другими инструментами управления магазином.
