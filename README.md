# DebtBook

**DebtBook** — Android-приложение для небольших магазинов и малого бизнеса, которое помогает удобно вести учёт долгов клиентов, платежей и операций.

## Зачем нужен DebtBook

Во многих небольших магазинах долги постоянных клиентов всё ещё записываются в тетрадь, заметки телефона или таблицы. Такой подход неудобен, повышает риск ошибок и затрудняет работу нескольких сотрудников.

DebtBook объединяет учёт клиентов, задолженностей и платежей в одном приложении.

## Основные возможности

### 👥 Клиенты и долги
- Добавление и управление клиентами.
- Учёт текущих задолженностей.
- Регистрация платежей.
- История операций.
- Автоматический расчёт баланса.
- Работа без постоянного подключения к интернету.

### 🏪 Магазин и сотрудники
- Создание магазина.
- Поддержка ролей **OWNER** и **EMPLOYEE**.
- Добавление сотрудников.
- Разделение доступа между участниками магазина.
- Защита данных разных магазинов.

### 🔐 Аутентификация и безопасность
- Вход через Google.
- Регистрация через Email.
- Подтверждение аккаунта.
- Supabase Auth и PostgreSQL.
- Row Level Security (RLS).
- Серверная проверка доступа.
- Защита пользовательских данных.

### ⭐ Подписка PRO

**Бесплатный план:**
- До 100 должников.
- Добавление одного сотрудника.
- Основной функционал учёта долгов и платежей.
- Ограниченный доступ к дополнительным возможностям.

**PRO-подписка:**
- Снятие ограничений бесплатного плана.
- Расширенные возможности управления магазином.
- Доступ к дополнительным функциям приложения.

## Технологии

- **Kotlin**
- **Jetpack Compose**
- **Android**
- **Room**
- **Supabase**
- **PostgreSQL**
- **Row Level Security (RLS)**
- **Kotlin Coroutines / Flow**

Проект использует разделение на UI, Domain и Data слои и построен с учётом offline-first подхода.
